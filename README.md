# MyMonTeam

MyMonTeam is a Pokémon team-building website currently in development. The goal is to create a tool that allows players to build teams of up to six Pokémon and analyze type matchups, weaknesses, and resistances.

## Current Progress

- Fine-tuned the search bar from the previous version to include only Pokémon in the currently selected game.
- The ability to select a Pokémon from the search bar, either through pressing the "Enter" key or a mouse input.
- Upgraded the displaying of sprites to be based on the selected game.

## Future Plans

- Adding a feature to input the moves each Pokémon on the team currently has.
- Giving functionality to the "calculate" button which will display various statistics about the team.
- Changing the game selector to act as a "Home Screen" for simplicity purposes.

## Technologies

- HTML
- CSS
- JavaScript
- PokéAPI

## AI-Assisted Development
MyMonTeam was developed with assistance from AI tools, which I use as a resource for learning and implementation. I lead the project's planning and feature design, make decisions about its functionality and user experience, and work through the underlying logic of each feature. I use AI to help implement unfamiliar concepts, explain code, and speed up development when I could otherwise spend significant time searching through tutorials and documentation.
