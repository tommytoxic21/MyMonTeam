# MyMonTeam

MyMonTeam is a Pokémon team-building website currently in development. The goal is to create a tool that allows players to build teams of up to six Pokémon and analyze type matchups, weaknesses, and resistances.

## Current Progress

- Initial website layout built with HTML and CSS.
- Basic page structure and generation selection menu implemented.
- JavaScript functionality and team analysis features are planned.

## Technologies

- HTML
- CSS
- JavaScript (in development)
